IntelliGPA
Project Overview

IntelliGPA is an AI-powered academic management platform designed to help students organize coursework, track grades, manage assignments, and visualize academic progress in one centralized dashboard.

The platform combines traditional productivity tools with intelligent automation to reduce the manual work students face when managing multiple classes, deadlines, and GPA calculations.

Users can:

Upload course syllabi for automatic assignment and deadline extraction
Track assignments, grades, and course performance
Visualize GPA trends and academic standing
Manage schedules through an integrated academic calendar
Monitor progress across all enrolled courses
Automatically organize important academic dates and deadlines

The system is built with a modern full-stack architecture:

Frontend: Next.js + React + TypeScript
Backend: FastAPI (Python)
Database: PostgreSQL
AI/NLP Processing: Syllabus parsing and assignment extraction
Core Features
AI Syllabus Parsing

Students can upload syllabus documents, and IntelliGPA automatically extracts:

Assignment names
Due dates
Exams and quizzes
Important course deadlines

The extracted information is converted into calendar events and assignment entries.

GPA Tracking

The application calculates and visualizes:

Current GPA
Course averages
Grade distributions
Academic trends over time
Assignment Management

Users can:

Create and edit assignments
Set priorities and statuses
Track submission progress
Monitor upcoming deadlines
Academic Calendar

The integrated calendar provides:

Assignment due dates
Exam schedules
Course events
Timeline-based academic planning
Course Management

Students can organize:

Course information
Credit hours
Instructor details
Grade weighting systems
Goal

IntelliGPA aims to simplify academic organization by combining productivity tools with AI-driven automation, helping students stay organized, improve time management, and maintain awareness of their academic performance throughout the semester.
